# DNS Lookup Tool

A simple Python tool that resolves a domain name into its IP address.

## Features

- Resolve domain names
- Display IPv4 address
- Error handling for invalid domains

## Requirements

- Python 3.x

## Run

```bash
python dns_lookup.py
```

## Example

Input:

```
google.com
```

Output:

```
Domain : google.com
IP Address : 142.250.xxx.xxx
```

## Educational Purpose

Use this project to learn about DNS resolution and basic networking in Python.
